THREE VIEWS · ONE SERVICE

每个人只看见自己需要完成的事

01 · 学生

完成资料与沟通偏好

通过一次性邀请填写资料，在清晰边界内补充求职目标和沟通偏好。

02 · 老师

记录进展与明确下一步

围绕自己负责或协作的学生连续跟进，留下可交接的行动信息。

03 · 老板

查看全局与处理例外

掌握团队负载、待办风险和协作范围，在需要时完成人工复盘。

THE SERVICE LOOP

一条可持续交接的服务链路

  1. 学生填写资料与沟通偏好
  2. 老师执行跟进、记录与下一步
  3. 老板复盘全局、风险与协作范围
  4. 继续跟进把反馈带回下一轮服务

CLEAR BOUNDARIES

前端、后端和官网各自独立

三个仓库通过同源 API 契约连接；官网只负责解释产品，不接触业务数据。
